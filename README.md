# Designer Revolution

Landing page estática do Pack Designer Revolution.

## Publicar no GitHub Pages

1. Extraia todos os arquivos deste ZIP na raiz do repositório.
2. Envie os arquivos para a branch `main`.
3. No GitHub, acesse **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main`, a pasta `/ (root)` e salve.

O site usa apenas HTML, CSS e JavaScript, sem instalação ou processo de build.
